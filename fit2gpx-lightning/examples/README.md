# fit2gpx-lightning Examples

This directory contains practical examples demonstrating how to use fit2gpx-lightning with real data.

## Quick Start

```bash
# 1. Quick installation test
python examples/quick_test.py

# 2. Run benchmark comparison
python examples/benchmark.py

# 3. Process Strava export
python examples/process_strava.py ../strava.zip

# 4. Process Garmin export
python examples/process_garmin.py ../garmin.zip
```
